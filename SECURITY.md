# Reporting a security vulnerability

Reportá hallazgos a **jarguetam** (GitHub security advisory en este repo, o el email del owner).

No abras un issue público con PoC de RCE, secretos o acceso cross-tenant.

Incluí: impacto, pasos de reproducción, `request_id` si aplica.

Rotación de secretos: `docs/runbooks/secrets-rotation.md`.
