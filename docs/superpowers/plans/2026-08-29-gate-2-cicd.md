# Gate 2 — CI/CD y entornos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staging aislado + CI fail-closed (lockfile, lint, pgTAP, deno, gitleaks) + Vite/Playwright en CI contra staging + promoción manual a prod. Pages **solo** producción.

**Architecture:** GitHub Environments `staging`, `production`, `eas-android`. Proyecto Supabase staging nuevo (Gate 0). Prod `xcoeipsnykceorcvjwve` no recibe `db push` desde PRs. Spec: Pages aloja únicamente producción; staging levanta Vite en CI.

**Tech Stack:** GitHub Actions, Pages (prod), Supabase CLI, Playwright, Node 22.14.0, pnpm 9.15.9.

**Spec:** Gate 2 del diseño  
**Índice:** `docs/superpowers/plans/2026-08-29-production-hardening-index.md`

## Global Constraints

- `xcoeipsnykceorcvjwve` = producción.
- Pages = solo producción. No crear site `/staging/` en github.io.
- Staging E2E = `vite preview` en el runner + `VITE_SUPABASE_*` de Environment `staging`.
- `pnpm install --frozen-lockfile`. Prohibido `--no-frozen-lockfile`.
- Node `22.14.0`. pnpm `9.15.9`.
- Ausencia de secret/migración/función/probe = fallo, no warning.
- Datos sintéticos en staging; nunca PII de prod.
- iOS / PWA / Storybook / i18n EN fuera.

export function requirePublicConfig(input: {
  url?: string | null
  anonKey?: string | null
  environment: 'local' | 'staging' | 'production'
}): { url: string; anonKey: string; environment: typeof input.environment } {
  if (!input.url || !input.anonKey) throw new Error('GC-CORE-001')
